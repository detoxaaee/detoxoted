git vs. gh: ¿Cuál es la diferencia?

Para actualizar tu código, vas a usar git. Aquí te explico por qué:

    git (Git clásico): Es el motor del control de versiones. Se encarga de rastrear los cambios en tus archivos locales, empaquetarlos (commits) y enviarlos (push) a un servidor remoto (en este caso, GitHub). Es la herramienta obligatoria para subir tu código.

    gh (GitHub CLI): Es una herramienta oficial de GitHub para interactuar con su plataforma desde la terminal. En lugar de usarla para subir código, la usas para gestionar cosas de la página web: crear Pull Requests, leer Issues, o crear un repositorio nuevo sin tener que abrir el navegador. Es excelente, pero es un complemento, no un reemplazo de git.

Cómo actualizar tu repositorio paso a paso

Asumiendo que la carpeta de tu proyecto se llama detoxoted y está en tu carpeta personal (/home/tu_usuario/), abre tu terminal y sigue estos comandos en orden:

1. Entrar a la carpeta de tu repositorio:
Bash

cd ~/detoxoted

2. Revisar el estado de tus archivos (Opcional, pero muy recomendado):
Esto te mostrará en color rojo los archivos que has modificado, creado o eliminado.
Bash

git status

3. Preparar los cambios para subirlos:
El punto (.) le indica a Git que quieres añadir todos los archivos modificados. Si solo quieres subir un archivo específico, cambias el punto por el nombre del archivo (ej. git add README.md).
Bash

git add .

4. Crear el "paquete" de cambios (Commit):
Aquí empaquetas los cambios y les pones una etiqueta para saber qué hiciste. Cambia el texto entre comillas por algo descriptivo.
Bash

git commit -m "Agregando nuevas funciones y corrigiendo errores"

5. Subir los cambios a GitHub (Push):
Como me compartiste tu enlace y veo que tu rama principal se llama main, este es el comando para enviar todo a la nube.
Bash

git push origin main

💡 Una nota importante sobre la autenticación en GitHub

Cuando ejecutes el paso 5 (git push), GitHub te pedirá tu nombre de usuario y tu contraseña.

Ojo aquí: GitHub ya no acepta la contraseña normal de tu cuenta por seguridad. Si te da un error de autenticación ("Authentication failed"), es porque necesitas usar un Token de Acceso Personal (PAT) en lugar de tu contraseña, o configurar una llave SSH en tu Linux.
